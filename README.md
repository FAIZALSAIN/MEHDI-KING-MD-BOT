**Step 1:** Neeche **GET PAIR CODE** button dabao 
**Step 2:** Apna WhatsApp number daalo `923xxxxxxxxx` ke format me
**Step 3:** Jo **Pair Code** aye usko WhatsApp > Linked Devices > Link with phone number me daalo
